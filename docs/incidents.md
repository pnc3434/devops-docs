# урнал типовых инцидентов

| нцидент | аблюдаемый признак | ервичный источник диагностики |
|---|---|---|
| еиспользуемая переменная | расная проверка `pylint` в PR | урнал шага Static analysis |
| едостаточные права публикации | `build` успешен, `deploy` не получает OIDC-токен | урнал `deploy-pages` и блок `permissions` |
| итая ссылка | `mkdocs build --strict` завершается ошибкой | урнал шага Build documentation |
| Старая версия после успешного деплоя | еленый workflow, прежнее содержимое в браузере | URL окружения, время публикации, кэш браузера |

## равило разбора
 разборе указываются симптом, затронутый компонент, доказательство из журнала, причина, исправление и проверка восстановления. твет «перезапустил и заработало» без установления причины неполон.
