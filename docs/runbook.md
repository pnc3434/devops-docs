# ксплуатация

## Штатная публикация
1. Убедитесь, что проверка `pylint` в Pull Request успешна.
2. ыполните слияние в `main`.
3. ткройте Actions -> Publish documentation.
4. ождитесь успеха заданий `build` и `deploy`.
5. ткройте URL из окружения `github-pages` и проверьте главную страницу.

## учной перезапуск
ля повторной публикации используйте Actions -> Publish documentation -> Run workflow.
устой коммит для этой цели не требуется.

## иагностика
Сначала определите отказавший этап: CI, сборка сайта, загрузка артефакта или публикация.
атем читайте журнал конкретного шага. овторный запуск без анализа причины не считается устранением инцидента.
